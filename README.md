## The line

> Our team-building exercise was trust falls, which is bold for a company that won't trust us to work from home.

## How it works

`main.ts` (Node 22, stdlib only) writes that one fixed line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Deterministic:
no input, no clock, no randomness, no network — the same line every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```
